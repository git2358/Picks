# [Picks](https://git2358.github.io/Picks/)

A simple random movie picker that helps you decide what movie to watch.

## What It Does

Picks randomly selects a movie from your movie collection and displays it as a movie card with:

- Movie poster
- Title
- Release year
- Synopsis
- Text-to-speech button
- Randomise button
- Full-screen cinematic presentation

The background dynamically uses the selected movie's poster to create a blurred, atmospheric backdrop.

## How to Use

1. Open **Picks** in your web browser.
2. A random movie is selected automatically.
3. Read the movie information and decide whether you want to watch it.
4. Press **Speak** to have the movie information read aloud.
5. Press **Pick Another Movie** to randomly select another movie.

## Design

Picks is designed to feel more like a small cinematic experience than a basic randomiser.

The selected movie is presented in a large card while the poster is used to create a blurred background. Red theatre curtains and a spotlight effect provide the movie-theatre look.

## Technology

Built using:

- HTML
- CSS
- JavaScript
- GitHub Pages

No framework or backend is required.
